# AICTE Cybersecurity and Ethical Hacking Internship

This repository documents my progress, practical labs, and custom projects completed during the **AICTE Cybersecurity and Ethical Hacking Internship (Zero to Defender)**.

## 🛡️ About the Internship
This internship program provides hands-on experience in cybersecurity and ethical hacking, progressing from foundational concepts ("Zero") to advanced defensive strategies ("Defender"). 

**Key areas of focus include:**
*   **The Threat Landscape:** Understanding malware, phishing, and social engineering attacks.
*   **Offensive Security & Ethical Hacking:** Identifying vulnerabilities and analyzing attack chains (Recon → Deliver → Exploit → Install → Control → Act).
*   **Defensive Strategies:** Implementing core defenses like MFA, patch management, and secure backups to break the attack chain.
*   **Practical Application:** Building custom security tools and working within virtualized lab environments.
*   
## 💻 Lab Environment & Tech Stack
*   **Virtualization:** VirtualBox, VMware
*   **Operating Systems:** Kali Linux
*   **Target Environments:** OWASP Juice Shop, Metasploitable
*   **Languages & Libraries:** Python
